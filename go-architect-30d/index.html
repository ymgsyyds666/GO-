核心文档

先跑起来

cd go-architect-30d\code
$env:GOOS='windows'; $env:GOARCH='386'    # 仅当你把 GOOS 设成过 linux

go run ./basics          # 语法：切片 / map / 接口 / 泛型 / 错误链
go run ./concurrency     # 并发：worker pool / pipeline / 限流 / 超时
go run ./web             # HTTP：中间件链 + 优雅关闭
go run ./ocr             # OCR：灰度化 + Otsu 二值化
go run ./llm             # LLM：SSE 流式解析（内置假服务，无需 API Key）

全部基于标准库，无需下载依赖；每个程序自带断言，跑通即验证。

三条铁律

  1. 只跑通不算会，能改才算会。每段示例敲完，必须做一次破坏性修改：改并发数、去掉 defer、把缓冲 channel 换成无缓冲，观察会发生什么。
  2. 先跑通，再优雅。第一遍用 log.Printf 和 println 都行；分层、接口、依赖注入是第二轮的事。不要一上来就学 K8s 和 DDD。
  3. 每天一个 commit，每周一个能跑的项目。GitHub 的提交记录和 README，比任何证书都更能证明你会写 Go。
